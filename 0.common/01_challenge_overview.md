## 2. 한 줄 요약

> **20년 넘게 쌓인 MODIS 화재 핫스팟과 최신 VIIRS 핫스팟을 "센서 차이가 사라지도록" 통합(harmonize)하고,
> 사용자가 지정한 지역의 "연소 활동 캘린더(burning activity calendar)"를 보여주는 웹 앱을 만들어라.**

## 3. 문제 배경 (원문 요지)

1. **화재 체제(Fire regime)의 변화** — 일부 생태계는 주기적 화재가 필요하지만, 강도·면적·빈도의 변화는 기후·사회·생물다양성에 악영향. 화재는 점점 더 인간 활동(농업 소각, 개간, 폐기물 소각, 산업)과 연관됨.
2. **위성 화재 탐지** — 중적외선(MIR)·열적외선(TIR) 센서가 산불, 화산, 가스 플레어 등 지표 열점(hotspot)을 탐지. MODIS·VIIRS가 대표적.
3. **핵심 문제** — MODIS(Terra/Aqua)는 2000년대 초부터 20년+ 기록을 갖고 있지만 **수명 종료가 임박**했고 VIIRS로 대체 중. 두 센서는 **공간해상도·민감도·관측 시각이 달라 직접 비교 불가** → 장기 시계열이 끊김.
4. **현장 수요** — 재난 관리자는 "어느 달/어느 해에 화재가 가장 많았나", "이번 달이 과거 중앙값 대비 어떤가"를 빠르게 보고 싶어함.

## 4. 요구사항 정리

원문은 두 단계 접근을 제안한다.

### Part 1 — 하모나이제이션 (데이터/과학 파트)
- MODIS + VIIRS 핫스팟을 통합하여 **센서 출처가 더 이상 중요하지 않은** 일관된 시계열 생성
- 목표: 패턴·추세·이상치(anomaly)에 집중할 수 있는 데이터셋
- 권장 소스: **NASA Earthdata FIRMS**

### Part 2 — 웹 애플리케이션 (소프트웨어 파트)
- 입력: 하모나이즈된 핫스팟 데이터
- 사용자가 **지역(AOI)** + **기간** 선택
- **연소 활동 캘린더**: 2000년대 초 ~ 현재, 월×연도별 핫스팟 수
  - 연중 어느 시기에 화재가 많은가 (계절성)
  - 어느 해에 연소 활동이 많았나 (연도별 추세)
  - 현재 화재가 과거 대비 어떤가 (이상치)
- **컬러 램프**로 월별 차이 시각화 (접근성 고려)
- **분석 결과·시각화 다운로드**, 검색된 핫스팟 **CSV 다운로드**

### 선택 고려사항 (Potential Considerations)
| 항목 | 해석 |
|---|---|
| 대상 사용자: 조기경보/긴급대응자, 과학자, 토지관리자, 소방관 | 전문가용이지만 비전문 현장 인력도 빠르게 읽을 수 있어야 함 |
| 지도에서 AOI 그리기 또는 위경도 입력 | 폴리곤/사각형 드로잉 + 좌표 입력 둘 다 |
| 접근성 있는 컬러 램프 | 색각이상 친화(viridis, cividis, YlOrRd 등) |
| 연소 캘린더 표현 | 월(열) × 연도(행) 히트맵이 가장 직관적 |
| 핵심 지표 소수에 집중 | 다년 평균/중앙값 대비 이상치, 탐지 화재 수 |

## 6. 평가 관점에서 본 차별화 포인트

Space Apps의 일반 심사 기준(영향력, 창의성, 타당성, 발표, 챌린지 적합성)에 비추어:

1. **하모나이제이션의 과학적 타당성** — "그냥 합쳤다"가 아니라 MODIS-VIIRS 중첩 기간(2012~)으로 **보정 계수를 산출하고 검증**한 결과를 보여주는 것이 가장 큰 차별점.
2. **보정 전/후 비교 시각화** — 2012년 전후 시계열 단절(step change)이 보정 후 사라지는 그래프는 심사위원에게 즉시 설득력 있음.
3. **현장 사용성** — "이번 달은 평년 대비 +240% (상위 5%)" 같은 한 문장 요약.
4. **글로벌 적용성** — 특정 국가가 아니라 전 세계 어느 AOI에서도 동작 (CONAE 제공 챌린지이므로 남미/아르헨티나 데모 지역을 포함하면 좋음).
5. **투명성** — 불확실성(신뢰구간), 사용한 센서/보정 방법을 UI에 표기.

## 7. 핵심 키워드 사전

| 용어 | 의미 |
|---|---|
| Hotspot / Active fire | 위성 픽셀 내에서 탐지된 열 이상(현재 타고 있는 불) |
| FRP (Fire Radiative Power) | 화재 복사 에너지(MW), 화재 강도 지표 |
| Harmonization | 서로 다른 센서 기록을 통계적으로 일관되게 맞추는 작업 |
| AOI (Area of Interest) | 사용자가 선택한 분석 지역 |
| Burning activity calendar | 월×연도 행렬로 핫스팟 수를 색으로 표현한 그림 |
| Anomaly | 다년 평균/중앙값 대비 편차 |
| NRT / SP | Near Real-Time(수 시간 지연) / Standard Product(정밀 처리 아카이브) |
